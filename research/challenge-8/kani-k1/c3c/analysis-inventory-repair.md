## What the pin supports

- [`kani-driver/src/args/list_args.rs`](https://github.com/model-checking/kani/blob/9461e07af7ec929f050aa4192f29363c9be07779/kani-driver/src/args/list_args.rs) defines list args as common args plus output format (and `--std` for standalone mode). It has no `--harness`, `--include-pattern`, or `--exclude-pattern` field. `--format json` changes serialization only.
- [`kani-driver/src/main.rs`](https://github.com/model-checking/kani/blob/9461e07af7ec929f050aa4192f29363c9be07779/kani-driver/src/main.rs) routes `list` directly to `list_cargo` / `list_standalone`. In [`list/collect_metadata.rs`](https://github.com/model-checking/kani/blob/9461e07af7ec929f050aa4192f29363c9be07779/kani-driver/src/list/collect_metadata.rs), that first builds the project and only then processes metadata. [`project.rs`](https://github.com/model-checking/kani/blob/9461e07af7ec929f050aa4192f29363c9be07779/kani-driver/src/project.rs) `std_project` calls `cargo_build_std`; `Project::try_new` iterates all metadata proof and test harnesses to link their models. There is no list-side prefix filter before this work. This matches C3b's recorded ~49-minute bare-list runs.
- `--harness` is a `VerificationArgs` option, documented as a filter for which harnesses to run ([`args/mod.rs`](https://github.com/model-checking/kani/blob/9461e07af7ec929f050aa4192f29363c9be07779/kani-driver/src/args/mod.rs)). `verify_project` applies `determine_targets(project.get_all_harnesses())` after project construction. Thus `verify-std --only-codegen --harness <prefix>` can avoid CBMC proof execution, but is not an early codegen/list filter, and source does not confirm it as a fast inventory route. `--only-codegen` does not produce the list; `--no-codegen` returns an empty project and cannot provide inventory.
- `autoharness --include-pattern/--exclude-pattern` are regular expressions selecting functions for automatic harness generation, and `--list` lists that autoharness project ([`args/autoharness_args.rs`](https://github.com/model-checking/kani/blob/9461e07af7ec929f050aa4192f29363c9be07779/kani-driver/src/args/autoharness_args.rs), [`autoharness/mod.rs`](https://github.com/model-checking/kani/blob/9461e07af7ec929f050aa4192f29363c9be07779/kani-driver/src/autoharness/mod.rs)). They do not filter manual `#[kani::proof]` harnesses; this is also recorded in `c3b/SOURCE-NOTES.md`. This cannot stand in for ordinary manual inventory.
