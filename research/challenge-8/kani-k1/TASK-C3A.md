## Зачем

Владелец решил: на каждое замечание организатора к прежним решениям Ch8 — либо решение, либо обоснованное ограничение. Из отзывов feliperodri ([#576, 12.09](https://github.com/model-checking/verify-rust-std/pull/576#pullrequestreview-5188053006), [#576, 16.08](https://github.com/model-checking/verify-rust-std/pull/576), [#678, 13.09](https://github.com/model-checking/verify-rust-std/pull/678#pullrequestreview-5188832758) — читать только тексты отзывов, не код PR) у нас открыты два пункта:

1. «`has_efficient_in_place_swap` only tested for u8/u64/u128; T-generic behavior for u16/[u8;9]/ZSTs/!Freeze not covered». У нас (`verify/smoke.rs:15–31`) есть ZST, `Cell<i32>` (!Freeze), нет `u16` и `[u8;9]`.
2. В #678 рецензент отметил как сильную сторону «genuine correctness oracles» (сортированность + мультимножество) на **реальных trait-входах** для `i32`, `Cell<i32>` (non-Freeze), non-Copy Freeze-типа, `u128`, `[u64;11]`, `u8`. У нас функциональная корректность — u8/u64; для `Cell`/non-Copy — безопасность и проверки Drop.

## Что сделать

0. **Инвентарь (без кода).** По `verify/*.rs` установить, что именно уже проверяет корректность (сортированность и/или перестановку) через реальные trait-входы `StableSmallSortTypeImpl::small_sort`, `UnstableSmallSortTypeImpl::small_sort`, `UnstableSmallSortFreezeTypeImpl::small_sort`: типы, длины, маршрут (fallback/general/network), какое из шести тел. Отдельно: дают ли семейства Drop/tag (`merge.rs` ≈1000–1220, `drop_route_properties`, `PERM`) перестановку и сортированность для non-Copy. Таблица в отчёте.
1. **Swap-предикат.** Добавить в `predicate_efficient_swap_type_matrix` `u16` и `[u8; 9]` с ожидаемыми значениями, выведенными из определения `has_efficient_in_place_swap` (записать вывод `file:line`). Имя гармоники не менять.
2. **Корректность для !Freeze и non-Copy через реальные trait-входы**, только если п. 0 показал пробел: новые ordinary-гармоники «сортированность + сохранение мультимножества» (существующая схема пробы/счётчика, без `assume` на выход), вызывающие реальный trait-метод (не внутренний помощник), для:
   - !Freeze: `Cell<u8>` (или `Cell<i32>`) — stable и unstable default-путь;
   - Freeze non-Copy: тип-обёртка без `Copy` (существующий `DropValue`/аналог, если подходит) — путь, который он реально выбирает.
   Длины: граничные и характерные для выбранного маршрута (минимум 0, 1, 2, порог-1, порог, и несколько внутри), до порога маршрута (fallback 16), насколько позволяют время и память. Перед выбором длин — оценить по сходным существующим гармоникам. Имена — по схеме пакета (`<свойство>_<маршрут>_<тип>_n<N>`), комментарии — сухо, 1–3 строки на семейство.
