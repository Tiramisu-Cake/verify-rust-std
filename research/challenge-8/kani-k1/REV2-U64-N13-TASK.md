## Три корня

Общая геометрия — живой инициализированный `[u64; 34]`, рабочий срез `v[1..14]`, размер и выравнивание `u64` в целевом Ubuntu X64. Один и тот же verification-only компаратор для всех корней выполняет полный `<` на `&u64` и сохраняет состояние. Допустим cover внутри компаратора. В handoff свяжи его семантику с `strict_less` из `network.rs`. Ключ `x >> 1` из fallback здесь неприменим. Три корня — plain `#[kani::proof]`, `#[kani::unwind(36)]`. Обе проверяемые функции исполняются реальным телом, без Check, Replace и loop contracts. На данном пине при `--no-assert-contracts` обычный вызов идёт в `ContractMode::Original`. Предикат области модели FIX3 ложен для `u64`. В plain Proof он не исполняется. [Предыдущая сверка режима](REV2-S13-BINDING-DESIGN.md) · [Компаратор network](/root/verify-rust-std-rev2-n26-n31-copy-back-w15/library/core/src/slice/sort/shared/smallsort/verify/network.rs:735)

| Слот / суффикс selector | Проверка | Исход |
| --- | --- | --- |
| `U64-N13-SWAP`, `u64_n13_swap` | Actual `swap_if_less` на произвольных полных `u64`. Указатель на `v[1]`, произвольная пара `0 ≤ a < b < 13`. В `v[1+a]` и `v[1+b]` нужны `min` и `max` исходных значений, остальные 32 элемента массива равны снимку. | `VERIFIED`, exit 0 |
| `U64-N13-S13-BITS`, `u64_n13_s13_bits` | Actual `sort13_optimal(&mut v[1..14], ...)`, 13 независимых битов представлены как `0u64/1u64`. Внешние элементы произвольны. Пост проверяет полные `u64` на принадлежность `{0,1}`, сохранение внешних элементов и каноническую отсортированную маску с исходным popcount. | `VERIFIED`, exit 0 |
| `U64-N13-S13-CORRUPT`, `u64_n13_s13_corrupt` | Тот же helper и компаратор, входная маска `0x0001` (единица на rel0). После actual возврата и cover изменить `v[1] ^= 1u64`. Ожидаемая маска `0x1000`, после порчи `0x1001`. Каноничность элементов и внешний frame по-прежнему проверяются. | `FAILED`, exit 1, ровно один отказ `REV2_U64_N13_S13_SORTED_POPCOUNT` |

- У листа swap ограничения входа относятся только к индексам. Снимок, сравнение и посты используют полные `u64`. Требуемые covers — компаратор вызван, `before[1+a] > before[1+b]`, строго меньшая пара, равная пара на двух разных позициях и нормальный возврат.
- Битовый positive должен покрывать все `2^13` масок, например через `kani::any::<u16>() & 0x1fff`. Сравнивай с `0x1fff ^ (0x1fff >> input_mask.count_ones())`. Обязательные covers у обоих корней — смешанный вход, вход с инверсией, actual вызов компаратора и возврат из sort13. Проверяй каноничность на полных `u64` отдельным постусловием. Усечение при построении маски не должно скрывать старшие биты. Контроль портит элемент, который прочитает тот же оракул. Его единственный отказ должен находиться на общей проверке порядка и popcount. [Образец проверки `u8`](/root/verify-rust-std-rev2-n26-n31-copy-back-w15/library/core/src/slice/sort/shared/smallsort/verify/rev2_s13_binding.rs:21)
- Зафиксируй все 45 пар actual `sort13_optimal` в порядке исходника и проверь `a < b < 13`, тот же тип, срез, адреса и компаратор, что у листа. В handoff дай короткий пороговый аргумент. Для каждого `t: u64` min/max переводят `x ≥ t` в AND/OR. Порядок всех проекций даёт порядок полных значений, разности соседних счётчиков дают полные кратности, а счётчик на `u64::MAX` даёт его кратность напрямую. На N13 actual `small_sort_network` после sort13 вызывает пустой цикл вставок и возвращается по `len < 18`. Зафиксируй перенос к этой ветке по исходнику. Это внешний аргумент для будущей приёмки, `stub_verified` и штатное покрытие pr752 требуют своих оснований. [Правило композиции](REV2-COMPOSITION-RULE.md) · [Прецедент N13](REV2-N13-ADMISSION-APPROVAL.md)
