## Фрагмент GOTO для ручной привязки Cell N8

Сохрани режим `MANUAL_REVIEW` и `UNKNOWN` для write set в receipt и summary. Переиспользуй batch3 collector. Изменение касается отбора **непрерывных блоков функций**, без нового автоматического парсера DFCC, анализа переходов или вердикта о binding. В batch3 окна вокруг упоминаний пропустили создание `[1..9]`, вызов trait и привязку write set в wrapper. На этом повторе приоритет получают целые блоки от заголовка до `END_FUNCTION` точного root, Cell default trait entry/диспетчера, зарегистрированной Check closure, wrapper из `--enforce-contract` и `contract::<checked_symbol>::assigns`. Используй имена из фактически выполненных команд и заголовков GOTO для отбора. Сохрани все инструкции этих блоков, включая метки `GOTO`, аргументы вызовов и запись `insert_object_upto`. Сами команды и исходные строки будут сопоставлены офлайн. Если блок не найден либо усечён, укажи его и причину.
