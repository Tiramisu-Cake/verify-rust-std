Задание для w14. Подготовь офлайн-сверку составного графа и один будущий Ubuntu-пакет. Координатор принимает конкретный вход `0x0001_0001` для проверки чувствительности общего поста. Утверждение для всех входов опирается на завершённый битовый Proof и составной байтовый граф. Базы в отдельных worktrees — Std `b93859fb447a39c0c8c7d854f70dedf9a47b263f` и control `b3b6b42b845e2a590149d6d0d2e430c3a2f95427`. Работа локальная, без CI, push, изменения Actions variables и запуска cargo, rustc, Kani или CBMC. Runtime и формула поста маски сохраняются. ## Конкретный контроль

Добавь opt-in plain root `n32_composite_witness_corrupt`. Используй общий helper и тот же post `REV2_N32_ACTUAL_CANONICAL_SORTED_POPCOUNT` из старой пары. Если helper получает маску параметром, сверь эквивалентность тела и независимых входов прежнего положительного корня. В новом root literal `0x0001_0001` задаёт внутренние канонические байты. В каждой половине есть единица в префиксе, rel13 равен нулю. Это обеспечивает сдвиг на первой вставке с обеих сторон. Оставь q и `v[0]`/`v[33]` произвольными. Actual `small_sort_network` проходит с обоими S13, вставками, merge и copy-back без stubs, Replace и нативного merge loop contract. После cover actual возврата и до общего поста измени `v[1]` через `^= 1`. [Исходная пара](/root/verify-rust-std-rev2-n32-consumer-w14/library/core/src/slice/sort/shared/smallsort/verify/rev2_n32_consumer.rs:11)

Для допуска контроля требуй `FAILED`, exit 1 и ровно один native `FAILURE` на общей метке, с совпавшими ID/class/location в regular и stock export. В request фиксируй координаты и имя функции из нового commit. Сохрани пять covers для actual пути, успешные q/frame и safety/overflow/unwind. `RSS_LIMIT`, timeout, посторонний отказ или неполная проекция оставляют контроль открытым. Результат относится к чувствительности поста на конкретном actual пути. Прежний `N32-ACTUAL-BITS` остаётся `VERIFIED` с VT 125,58 с вне профиля. Новый диагностический отчёт проверяет свои слоты и не присваивает старой паре `PAIR_WITHIN_PROFILE`.
