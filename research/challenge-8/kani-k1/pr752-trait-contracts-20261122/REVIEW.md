## Семантика и форма

На каждом теле один `cfg_attr(kani, ensures(...))`. В обоих `old` сохраняются значения, `bool` для guard и `SortSnapshot: Clone + Copy` для `v`. Снимок читает только initialized active slice при допустимой длине даже при вычислении `old` с выключенным guard. Generic fallback выключает модель и ничего не разыменовывает. Checker проверяет числовой порядок и кратности полных значений, без вызова компаратора. При N2 он сравнивает две перестановки пары. При N3 сохранённые кратности всех входных значений при равной длине исчерпывают выход. Frame обоснован только для exact read-only callback и объявленной геометрии.
