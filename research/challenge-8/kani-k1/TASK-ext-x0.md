## Что сделать

Результат — новый файл `research/challenge-8/kani-k1/EXT-X0-BASELINE-2026-10-28.md` и два черновика заданий. Чужие файлы не править.

1. **`S_M` и реестр E_M.** SHA, список всех SmallSort-гармоник `S_M` из исходников (модули `kani_k1` и `correct`): путь, тип, N/домен, вид (safety / correctness / control), cfg (входит ли в стандартный `kani list`). Число по модулям. Сверить с числами RESULT W3-L1/L2; расхождение — явной строкой, не правкой.
2. **Остаток М.** По `W3-REQUIREMENTS.md` на `b6b480cc` — точный список незакрытых и частично закрытых клеток М (в т. ч. A2/A4/B6/C2/C3/F1 из §3 плана, E1/uninit, ZST при N≥18, bounded insertion до 20). Для каждой: что именно не покрыто (типы, длины, scratch, preconditions callee), какой X её закрывает или «вне первой волны».
3. **Таблица T/P/H/M.** Структура по §4.1 для {ubuntu, macOS} × p1..4. Заполнить то, что уже измерено (macOS L1-8 — с пометкой «ранний кандидат 5c713131»; GCB — только калибровка, не Ubuntu). Клетки финального CI — `TODO (coordinator, final CI)`; координатор впишет их сам.
4. **Source-проверка X6.** По upstream-коду `smallsort.rs` на `S_M`: сигнатуры и фактические предусловия `merge_up` / `merge_down` / `bidirectional_merge` (указатели, длины, нечётный хвост, aliasing src/dst). Можно ли повесить на `merge_up`/`merge_down` Kani-контракты (`requires`/`ensures`/`modifies`) без изменения runtime-поведения, и какие обёртки/stub для этого нужны. Что из X6 а/б/в проверяемо этим путём, где вероятен blocker. Без кода гармоник — только анализ и точные ссылки `file:line`.
5. **Source-проверка X7.** Реальны ли маршруты u8 (17,1), (20,1) для direct insertion и (10,9), (16,13) для network-регионов: из каких вызовов `small_sort_*` и при каких `len`/порогах они достижимы. Для insert_tail на 18..20 — совместимы ли более короткие регионы и backing allocation (§5.1 X7). Если маршрут недостижим, пометить blocker и предложить замену.
6. **Черновики заданий** `TASK-ext-x6.md` и `TASK-ext-x7.md` в том же каталоге — в формате прежних `TASK-w3-*.md`: цель, вход (`S_M`), шаги, gates/STOP из §5.1, cap ($6 / $2), lane (Cloud Build e2-standard-4 16 GB, `measurement` ≤600 с, `jobs` 1), контроли, критерий завершения.
