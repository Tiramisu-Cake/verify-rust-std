## Проверяемые обязательства

- **Cell.** Инициализированный backing `[Cell<u8>;34]` из 34 независимых полных байтов, активный `v[1..N+1]`, все внешние значения произвольны и проверяются через `Cell::get`. Используй точный `CellCmp` (fn pointer) со значением `canonical_less_cell`. Вызов default Unstable ведёт в `small_sort_fallback`, затем `insertion_sort_shift_left(v, 1, ...)`. В opt-in ветке `SortModel` активируй **Unstable** для этих длин с каноническим компаратором. Сохрани действующие ветки N2 и другие пары/длины. Текущий снимок покрывает максимум три значения. Для новых длин нужна собственная достаточная ёмкость, например opt-in часть снимка с 16 логическими байтами. Снимок `old` владеет копиями логических значений, читает только initialized active slice и проверяет границы до чтения. `ensures` детерминированно проверяет порядок и полные кратности. Сопоставление счётчиков для каждого исходного значения достаточно при неизменной длине. Сохранить write set `modifies(v)` и внешний frame. До вызова утверждение и cover `enabled`, после него cover полезного возврата. Активация через `assume` и недетерминированный probe внутри контрактного post недопустимы. [Default Unstable](/root/verify-rust-std-pr752-trait-contracts/library/core/src/slice/sort/shared/smallsort.rs:95) · [Работающий короткий Check](/root/verify-rust-std-pr752-trait-contracts/library/core/src/slice/sort/shared/smallsort/verify/trait_contracts.rs:184)
- **Примитивы.** Сохранить опубликованный домен initialized `[T;N]` и active base0 на всю allocation. Передавай один и тот же опубликованный `merge::lt_u8` или `merge::lt_u64` в actual fallback и в oracle порядка. Ключ равен `value >> 1`. Кратности считай по полным значениям, включая младший бит. Probe независим от входа и фиксируется до вызова. В той же allocation внешних слотов нет, запись вне неё проверяется штатными проверками указателей и bounds. Эти корни доказывают тело helper на точной геометрии. Primitive trait-вызовы выбирают другие тела. В карту не добавлять для них строку допуска trait `ensures`. [Опубликованные компараторы](/root/verify-rust-std-pr752-trait-contracts/library/core/src/slice/sort/shared/smallsort/verify/merge.rs:114) · [Опубликованный fallback и oracle](/root/verify-rust-std-pr752-trait-contracts/library/core/src/slice/sort/shared/smallsort/verify/merge.rs:342) · [Freeze + Copy dispatch](/root/verify-rust-std-pr752-trait-contracts/library/core/src/slice/sort/shared/smallsort.rs:189)
- **Для всех.** Реальные `insertion_sort_shift_left`, `insert_tail` и `CopyOnDrop`. При N≥2 offset ровно 1, tail offsets от 1 до N−1 включительно. Положительные входы произвольны и полностью инициализированы. Компаратор чистый и реализует порядок своего домена. В будущей native-проекции нужны достижимый useful return и covers на отсортированный и строго убывающий входы по тому же компаратору, а также дубликаты полных значений. У примитивов добавь cover пары разных значений с одинаковым ключом. Свяжи входы с ветвями раннего возврата и полного сдвига по исходнику. Сохрани обычные safety, overflow, bounds, unwinding и reachability свойства, без verified/ordinary stubs. Стартовые unwind — 36 у Cell для V34 и 34 у примитивов по опубликованной схеме. Обоснуй каждый по реальным циклам и проверь resolved unwind при будущем запуске. N16 вызывает 15 хвостовых вставок, для которых суммарная исходная граница сравнений 120. Это граница работы тела, ресурсный вывод требует измерения.
