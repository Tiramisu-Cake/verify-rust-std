## Семантика

- Объект и смещение выбирают один байт shadow. Для `MaybeUninit<T> -> T` и `-> ManuallyDrop<T>` проверка применяет маску данных T к адресу исходного операнда перед transmute. Проверки validity остаются в штатном pass.
- Получение raw-адреса слота или его поля сохраняет shadow. Запись поля обновляет маску поля по его адресу. Создание пустого слота очищает весь его размер.
- Целый слот переносит shadow при присваивании, копировании и передаче через вызов с MIR. На пути, отслеживающем исходный байт копирования, shadow переходит к соответствующему байту назначения. Старое состояние перезаписанного байта назначения исключается на остальных путях.
- Плоские массивы и срезы слотов используют размер элемента для смещений и переноса. Извлечение значения проверяет маску данных самого T. Сценарий U6 требует `MaybeUninit<[u8; 4]>` для результата merge, для него есть отдельный harness.
- Произвольные и вложенные union остаются за пределами новой поддержки. Динамический repeat слотов, потенциально перекрывающийся MIR array aggregate, `typed_swap`, возвраты без MIR и вызовы через fn-pointer вне области патча.

## Проверки

- PASS для `validate` и `prepare-kani` на свежем checkout. Последний проверил SHA-256, выполнил `git apply --check --index` и сверил пути фикстур и companion-файлов.
- PASS для `git diff --check` и `rustfmt --check` на применённом дереве. Production 7 файлов, +530/−150. Новые тесты и golden 16 файлов, +254. Существующие golden и tooling совпадают с базой.
- Один положительный selector с шестью harnesses проверяет инициализацию, чтение целого слота через raw pointer, padded T через `ManuallyDrop`, частичный copy, offset среза и массив T для U6. Требуется успешный Kani exit.
- Семь отрицательных selectors ожидают конкретную uninit-диагностику из собственного вывода. Golden привязывают FAILURE к harness или safety property и требуют `VERIFICATION:- FAILED`. Случаи включают overwrite частично пустым источником, пустого соседа и reset с последующим чтением через alias.
- Девять selectors покрывают штатные union, copy, padding и delayed-UB регрессии. `fixme_unions.rs` и `slices_fixme.rs` имеют статус NOT_RUN.
- Native результаты ожидаются после GO. Локально Kani, cargo, rustc и CBMC не запускались.
