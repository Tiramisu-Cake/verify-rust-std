GO на CMP3 как локализацию после следующих уточнений; CMP2 исправлением не считать.
1. Прямой доступ из uninit_probe.rs невозможен: IndexRange доступен, но PolymorphicIter/его API — pub(super), alive — private; array::iter тоже private.
2. Сделать минимальные #[cfg(kani)] диагностические адаптеры внутри iter_inner, с crate-visible доступом через array; настоящие методы/видимость типов не менять.
   Корни оставить opt-in под SmallSort: runner фиксирует этот префикс. kani_smallsort_controls вне разрешённых SmallSort-файлов запрещён текущим preflight.
   Явно включить адаптеры в scope TASK; это добавление диагностического std-кода, production-only Kani patch остаётся побайтно CMP2. Tooling не менять.
3. Семь исходных строк оставить. В (2–4) использовать штатный PolymorphicIter::len(); прямой alive.len() — только из адаптера внутри iter_inner.
   Для (4) явно задать ManuallyDrop → deref → unsize → len, сопоставимый с IntoIter::unsize. Учесть общую границу адаптеров при сравнении.
   В (5–6) предпочтителен IntoIterator::into_iter([a, b]), без устаревшего IntoIter::new и зависимости от edition method resolution.
4. Данные полностью инициализированы: [MaybeUninit::new(a), MaybeUninit::new(b)], alive=0..2; не добавлять побочный uninit через Drop.
   Проверять len==2, результаты next()==Some(a)/Some(b), затем None; cover после целевой операции. Ошибки Drop учитывать отдельно от len.
5. Добавить существующие U1/U2 — отрицательную/положительную калибровку uninit на том же core-пакете; U8 пока целевой интеграционный probe, не установленный PASS-контроль.
   Получится 9×3+30=57 мин, резерв $0.7695, cap $0.80; без автоматического повторного запуска. Исходные 7 строк: $0.6885.
6. Первый провальный шаг и KT2 Failed Checks локализуют наблюдаемый отказ, но не устанавливают причину: адаптеры, inlining, unsize и Drop меняют контекст.
   Все ступени PASS при U8 FAIL означают неполную локализацию; совпадение source span само по себе не связывает проверку с конкретным MIR-объектом.
7. Для различения гипотез нужны связанные данные transfer и delayed get: конкретный экземпляр функции/MIR-place, тип, base object + offset,
   диапазон/значения R до и после transfer, цели points-to и порядок Set/Copy/Get. Потеря R в той же области и get другой области — разные наблюдения.
   Сохранять идентичности build/head/patch и достаточные KT2-выдержки через Brief; обрезанный Failed Checks не считать полным перечнем отказов.
8. Не добавлять перед len «проверочный» raw-read/AddressOf: он способен изменить R/points-to и замаскировать механизм. Парные read/len-пробы дают лишь косвенные данные.
   Если нынешних артефактов для связи объектов недостаточно — причина UNKNOWN; отдельную ограниченную немутирующую трассировку согласовать следующим диагностическим шагом.
9. U4 держать: его исходное условие native CMP2 PASS не выполнено. CMP3 его не заменяет.
   После реального исправления повторить IntoIter/grouped-positive и отрицательные контроли; missing required u8 в padding-negative остаётся самостоятельным blocker.
   К U4 переходить после выполнения исходных gates и отдельного GO на точный новый пакет; не «лечить» ложный отказ тотальной инициализацией pointee/product.
