# Snapshot and lifecycle contract

R5 intake ebd77 establishes supervisor ProcessLookupError, later SIGTERM/worker-15
and missing required AFTER. Immutable byte drift and the throwing syscall/path
remain UNKNOWN. This candidate does not retrospectively diagnose or admit R5.

The S3 controller records immutable E0, invocation-specific Ei.pre, verified-tree
Ei.post and completed seals. Each epoch binds campaign/root/rank/invocation,
request digest, source/control parents, complete source identities, actual
binary path/hash set and control HEAD/tree/clean state. Every pre/post must match
E0; compilation never redefines it. Binary/source capture errors retain their
operation, errno and bounded traceback alongside other measured fields.

The surviving controller obtains post-state after the exclusive subreaper has
verified shutdown and reaping. This complements the worker's inner protected
AFTER: an interrupted worker's missing AFTER stays missing in its original group
receipt. A separate controller snapshot can establish observed post-state; it
does not fabricate worker execution or compilation success. Unknown containment,
real input drift, unreadable/missing post-state or uncertain aggregate output
accounting stops the campaign globally. Original child exit/signal, supervisor
exception and interrupted receipt survive. Later roots become NOT_RUN;
unselected historical/full obligations remain NOT_SELECTED.

Only exact ENOENT/ESRCH at identified disappearing process operations is treated
as a benign race, with an existing owned PID/start-time and re-observation of
absence/zombie state. Recycled IDs, unknown ownership, live unexplained ESRCH,
wrong errno and other errors reject. /proc enumeration disappearance never
establishes ownership. Events have bounded retained history and omission counts.
The controller records operation/errno/traceback/epoch and the eventual child exit.

Each singleton gets fresh target/export/metadata namespaces and before/after
binary measurements. Native selector starts/order and source/stage/target
bindings are checked; late publication changes row status to UNKNOWN without
mutating already durable supervision/lifecycle/seal facts. Completed prefix files
are sealed and rechecked; upload-only replay validates structured stock/rich/
metadata, exact source/target/cfg/unwind, dynamic role IDs and epoch identities.
Unexpected/unknown/U roles never acquire credit. No automatic retries/resume.

Local memory is sampled non-atomic PGID VmRSS6GiB; outer exclusive-owned process
sampling is12GiB with2GiB headroom. This is not strict cgroup/tree/kernel memory
accounting. Resource controls retain child600 including compile180, slot720,
9×720+controller180+cleanup240=6900, outer7500, step7560, phase8100,
setup aggregate1800 and job180min. Output/export/artifact caps are shared.
The existing tool build uses the remaining setup clock, capped900; individual
setup step maxima are not additive grants beyond the1800 aggregate.
