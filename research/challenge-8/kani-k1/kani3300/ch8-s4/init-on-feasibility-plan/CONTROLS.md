# Proposed controls — all NOT_RUN

All controls live in a future dedicated ON harness module, use Original actual-body calls without providers, fresh exact singleton invocations, and the frozen caps in INPUTS.json. No Rust implementation is added in this planning stage. Labels below are proposed stable IDs, not existing native properties. Record future compiler source/instance/operation IDs as well as literal labels.

## Minimal required positive and negative

Use live `MaybeUninit<[u8;2]>` storage; obtain raw `*mut u8` without making an initialized `[u8;2]` reference. Do not call whole-object `assume_init`. The direct outer union is only a candidate way to isolate scalar behavior; B-LAYOUT/B-ADDRESS must be resolved if setup or extraction lowers to unsupported operations or blesses unwritten bytes. A plain already-initialized array is not a valid substitute.

* **C0+ `INIT_ON_PARTIAL_WRITE_READ_OK`**: start with payload K=empty. Choose initialized arbitrary u8 x; actual `p.write(x)` initializes cell0. Assert the non-reading `Init_u8(p)`; then do actual typed `p.read()` and check it equals x. Never read/query cell1 as a value. End K={0}, R={0}, W={0}; cell1 remains unwritten. Require complete native safety/uninit/unwind success and useful-return cover. This is the minimal correct partial-initialization case.
* **C0− `INIT_ON_UNWRITTEN_CELL_READ`**: same storage, seed and write0. Do an actual typed `p.add(1).read()` and consume the result in an observable scalar/check so the read remains represented. At the operation K={0}, R includes forbidden cell1, W={0}; no successful defined return is expected, and there is **no P for a defined post-read state**. Require the native initialization check attached to that read to fail. Do not query/assert hole initialization first, because that could turn the intended read into an unreached secondary failure. Do not run an order/count oracle over the result. A cover immediately before the read plus operation/property binding must establish reachability. No downstream arbitrary value assertion can substitute for the uninit failure.

The sole intentional undefined read belongs to a negative control. The initialization oracle and functional/frame oracles never load an uninitialized cell. No `kani::assume(Init(...))`, assumed initialization bit, manual MEM_INIT_STATE write, branch filtering by Init, or weakened check is allowed in either harness. Geometry/order assumptions, if needed for later helper domains, are separate and cannot mention checker shadow state.

C0 is the minimum entry gate, not sufficient qualification of copy/layout/actual-helper paths. C3–C7 are mandatory before any affected path is claimed supported; C8/C9 are mandatory before claims about those actual bodies; C10/C11 discriminate missing and extra writes. B-MASK remains open if there is no sound exact store-footprint check for C11; a handwritten ghost mask with an assumed relation to real memory cannot close it.

Preserve all other native failures and statuses, even in negatives. Require an attributable uninitialized-read failure for read controls and an attributable Init assertion failure for C1. A compile error, unsupported assertion, unreachable read, unrelated overflow, frame failure, output-cap/timeout or missing export never qualifies as the expected control outcome. C0+ must retain one unwritten cell without reading it; C0− must fail the **read** check, not an oracle that ran first. None of these controls becomes an admitted provider automatically.
