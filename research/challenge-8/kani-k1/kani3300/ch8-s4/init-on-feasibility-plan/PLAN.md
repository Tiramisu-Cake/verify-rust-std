## What 0aac can do, by source inspection

* `-Z uninit-checks` enables compiler `--ub-check=uninit` and `-Z ghost-state`; it does not turn on the distinct `valid-value-checks` feature. Existing cfg(kani) installs the in-core API. OFF's `is_initialized` intrinsic instead returns true, so its success is not initializedness evidence. [CLI_FLAGS, ORACLE_OFF, CORE_INSTALL]
* Setup nondeterministically selects one object/byte and a false bit. Reads are checked; real stores update state; copy operations transfer it. Uninit safety uses **assert-no-assume**, after contracts/AnyModifies and before intrinsic generation. Global DelayedUb follows reachable casts/aliases and updates transformed bodies. The model is an assertion abstraction, not a concrete iterable initialization bitmap. [ORDER, HARNESS_INIT, MODEL_SETUP, MODEL_GET, UNION_WRITES, COPY_STMT, COPY_ALLOC_INTRINSICS, READS, GLOBAL_ORDER, DELAYED]
* In core, `crate::kani::mem::is_initialized::<u8>(p.add(i))` takes **one pointer** and queries state without a typed load from `p[i]`. The u8 layout checks one data byte. `can_write` checks bounds/alignment; it does not establish initializedness. `can_dereference` asserts initialization and then checks value validity; use only on known-initialized inputs. [MEM_API, MEM_PREDICATES, ORACLE_U8]
* Direct union predicates are explicitly unsupported. `is_initialized::<MaybeUninit<u8>>` is not a substitute for a u8-byte query. Arrays/structs with nested unions can hit `UnionAsField` even if the queried pointee is u8: assignment layout preflight also matters. A direct `MaybeUninit<[u8; N]>` has a different layout route from `[MaybeUninit<u8>; N]`, but pointer/field interactions still require checks. [ORACLE_UNION, LAYOUT_UNION, LAYOUT_BYTE_ARRAY, LAYOUT_NESTED_UNION, ASSIGN_PREFLIGHT, SET_UNION, READS]
* This pin already contains marker-based discovery of `MEM_INIT_STATE` for contract assigns and repeated-pair termination of the DelayedUb ancestor walk. Do not propose those as missing fixes or import a later PR as if it were part of this pin. Assigns lookup can still fall back to empty; actual symbol/assigns binding is a future gate. [ASSIGNS_SHADOW, DELAYED_STORES]

Only use `Init_u8` as a **positive assertion**. Never assume it, branch on it to filter executions, call shadow setters from a harness, or infer a full bitmap from successive results. For an untracked coordinate `get` returns true: `assert(!Init_u8(hole))` is not an exact negative-bit oracle. Copies can retarget the selected coordinate, so equality with an `old` query is not a whole-mask frame proof. A zero-sized/zero-length predicate is vacuous. [DEMONIC_USE, MODEL_GET, MODEL_COPY]
