Title: Analyze selected contract bodies and detect active call cycles

Refs #3300

Depends on #5172, which is still open. This branch is based on #5172; until that PR merges, its changes are included in this branch's diff against main.

With `-Z uninit-checks`, delayed analysis must use the selected MIR bodies for contract registration and discarded closures, and report active call cycles without exporting an incomplete points-to graph. This change also initializes ordinary scalar and reference argument slots before tracked reads, without initializing their referents.

### Change

- Track active analysis frames per entry root, preserve bounded cycle diagnostics, latch errors, and propagate failure so a partial graph cannot escape.
- Select registration and discarded-closure bodies with explicit provenance; retain the existing call-resolution and single-walk/common-flush behavior.
- Add ordinary scalar and reference entry setters without initializing referents or union storage.

### Limitations

This is not a full resolution of #3300. Delayed analysis cycles remain unsupported; function pointers, trait objects, `stub_verified`, and `kani::recursion` do not gain shadow-transfer support. This change does not add blanket `MaybeUninit`, indirect-call, or recursion support.
