# Ночь 2026-10-26/27: правила автономной работы

**Решение владельца (2026-10-26 ~20:10Z).** Ночью агенты работают по очереди заданий без согласований с владельцем. Координатор (Claude Code) остаётся на связи: делает review R9, принимает решения в рамках плана и следит за деньгами. Утром он пишет отчёт.

## Окно

- Новые dispatch можно отправлять до **2026-10-27T05:00Z** (08:00 МСК).
- Прогоны, которые к этому времени не закончились, не отменять. Записать их id, координатор дочитает.
- Агент, у которого кончилась очередь, пишет итог, ставит строку-маркер (ниже) и останавливается.

## Можно без владельца

- Задачи из очереди своего ночного задания, по порядку, с правом агента решать спорное по R7.
- Дробить гармоники, менять формулировку проверки внутри задачи, отступать по длине до наибольшей проходящей.
- Решения координатора (CD) в рамках плана R6 и CD-6.

## Ждёт утра (не делать)

- Поднимать любой денежный потолок. Cloud Build — $35, его проверяет `k1g.sh`.
- Опыты вне очереди, новые оси, изменения плана.
- Любые внешние действия: вопросы организаторам, PR, публикации, сообщения на GitHub.
- Новые агенты и смена исполнителя.
- Изменения lane, runtime std и чужих файлов гармоник.

## Деньги

- **CircleCI:** ночного потолка нет (владелец: «работаем как идёт»). Кредиты месяца сбрасываются 8 ноября. Если кредиты кончатся и CircleCI начнёт отказывать, агент записывает это и останавливается. На Cloud Build он сам не переходит.
- **Cloud Build (smallsort-k1):** не больше $35 всего, проверяет `k1g.sh`. Ночью его использует только расширенный слой (WX-ext).

## Технические правила ночи

- **GitHub** иногда отвечает HTTP 429. Повторять push и dispatch с паузами 5, 10 и 15 минут, не чаще.
- **Ожидание прогонов:** Codex — через `k1.sh watch`; Claude — фоновым `k1.sh wait` или `k1g.sh wait`.
- **Review:** строка `REVIEW REQUEST <полный SHA>` на коммит с кодом гармоник. Координатор отвечает сообщением в сессию.
- **Записи в RESULT:** кратко, в терминах проверок Kani. Новый раздел «Ночь 2026-10-27» в своём RESULT-файле.
- **База check-tooling CircleCI** остаётся `9de80e0bec13896bb35a5e04e771448d9fe3931b`. Базу в ветки агентов не вливать.
