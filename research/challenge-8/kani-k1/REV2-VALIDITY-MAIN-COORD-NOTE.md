# REV2 · валидность на Kani main · уточнение координатора

Дополняет [задание](REV2-VALIDITY-MAIN-IMPL-TASK.md) и имеет приоритет над ним.

1. **Раздел 0 локально не выполняется.** На этом сервере сборка Kani, cargo, rustc, Kani и CBMC запрещены владельцем. Совместимость main Kani `8c6dba5935` с неизменённым Std `dab03cf510` становится фазой 0 будущего CI-пакета. Фаза 0 включает сборку Kani, сверку версий nightly и компонентов, а также compile-only preflight Std с теми же witness и классификацией сбоев. Фазы A и B стартуют только после успешной фазы 0. Локально выполняется только статическая сверка: `rust-toolchain.toml` обеих сторон, компоненты, требования Kani к toolchain.
2. **Контекст работы.** Это формальная верификация стандартной библиотеки Rust (verify-rust-std Challenge 8) инструментом Kani. Контрольные корни с недопустимым битовым шаблоном нужны только для проверки чувствительности проверки валидности значений. Это обычные отрицательные тесты верификатора.
