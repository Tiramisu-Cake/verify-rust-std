## Точный домен и supplied premises

**Concrete u64, x86_64-unknown-linux-gnu, nightly-2026-09-25**, один local nongeneric CopyOnDrop, один scalar tail и literal guard.len1. Нет general T/ZST/arrays/other target theorem. Guard len1 **не означает array len1**: итоговый insert_tail должен работать с gap внутри multi-cell slice; этот adapter просто не доказывает backing slice или сдвиг.

Исходный caller требует thread_token(t), t=currentThread, type_interp<u64>, 0<size_of<u64><=isize::MAX, nonnull/aligned tail, object extent одного u64 и отсутствие address overflow, полный initialized `*tail |-> held` и own(held). Это предпосылки его entry, не вывод из полномасштабного insertion caller. Actual tail.read/ManuallyDrop constructor и initializer взяты из pinned SmallSort; physical guard/readonly tmp shares, source/destination identity/disjointness, initialized source quarter, full uninitialized gap и CURRENT ownership получаются внутри этого adapter. Method strong entry дополнительно требует bounds/nonoverflow/nonnull/alignment обеих сторон и singleton arrays. Canonical safety_proof начинает с канонического prototype/FBC/own, получает strong pre и возвращает effect; эти canonical proof premises не являются caller grants.

No Freeze/Copy/purity или comparator restrictions добавлены к generic safety: generic safety здесь вообще не заявлена. Результат не закрывает B1 целиком (required end/retirement negatives отсутствуют), B2, R5, O23 или actual insert_tail panic cleanup. PROGRESS-REVIEW baseline/индекс и исторические PASS tool I/as_mut_ptr/ManuallyDrop::new сохранены; нового балла entrypoint не начислено.
