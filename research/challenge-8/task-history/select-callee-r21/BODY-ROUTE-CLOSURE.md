# Inactive R21 body-route source closure

The new recipe selects `o26-sort4-body-r21` with exact UTF-8/XZ transport. It remains inactive and unregistered: the R21 body profile still has `cloud_build_enabled: false`, and there is no client or coordinator admission in this change. The closure is derived from the existing full C1 recovery recipe plus static reads from the R21 shell, entry, runner, body, tool, route preflight, and retained source helpers. `BODY-ROUTE-CLOSURE.json` records the exact path lists, roles, exclusions, and current working-tree byte counts.

Proof inputs retain the R21 profile and body/tool/cleanup modules; both C1/C2 constructors, all five declared Rust copy/recovery/permutation sources, and the pinned capture module; the R17 reference-own probe, AST gates, fixtures, and ghost grammar; and every std snapshot consumed by profile preflight, the full-source audit, and source certificate. These inputs preserve the route's 5 comparison calls, 8 select calls, 4 copies, and full resource/leak controls. The O26 refresh shell also needs its source-only `o26-refresh-recipe.py`/`o26-recipe.py` call chain and the nine-body preparation/capture/linkage/owner/drop sources. The full reconstruction chain retains the 20 frozen O26 patches, two refresh patches, and the R2/C4/C1/R15/R16/R17 patch, manifest, snapshot, and selected-binding inputs read by the pinned R21 tool, R21 body runner, selected-runtime helper, and legacy driver.

The infra recipe adds only the R21 run script, body-route preflight, R21 entry and runner, legacy driver, selected-runtime, first-scope audit, ghost stripper, and the two O26 refresh scripts. `source-input.py` adds its exact infrastructure core automatically: `run-proof.sh`, `control.py`, `coordination.py`, `exact-infra-transport-controls.py`, `package-evidence.py`, `provider.py`, `source-input.py`, and `verify-evidence.py`. Entry/runner/driver hashes are checked from `infra_root`; proof modules, profile, source snapshots, and patch chain are selected from `proof_root`.

The recipe excludes the 254 KB generic `a1-runner.py`; the R21 body imports the 6.6 KB cleanup helper for that operation. It also excludes `selected-proof.py`, which belongs to the conditional compiler-query/selected-prefix branch of the legacy driver; this route calls the full body path. The old R17 body/tool and R19 fallback profile are replaced by the R21 copies/profile. Static imports and profile-selected reads also show that generic call-binding, contract-admission, matrix/proof classifier, synthetic backend/input, summary receipt, and generic reference-own probe modules are not loaded on this route. The closure record lists each excluded file and its reason.

The current uncommitted recipe selects 135 proof paths and 10 explicit infra paths, with 8 more infra-core paths included by exact source-input policy. Current working-tree proof blobs total 2,388,484 bytes versus 2,786,364 bytes in the old recovery recipe, a 397,880-byte source reduction. This is not an archive-size claim. Because source-input only accepts committed recipes, no real payload was built or measured; main must commit the reviewed recipe and then measure the actual transport payload.
