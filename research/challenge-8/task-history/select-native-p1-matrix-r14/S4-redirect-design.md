# S4 forced redirect input-binding design

The R14 redirect negative intentionally stops in the translator before positive AST capture: the translator rejects the forced legacy clause-ignoring route. Therefore `collect_source_case` can return `INCONCLUSIVE_CURRENT_STAGE` after paired support, with its raw producer fields, before it constructs the outer `observed_input_ids`; requiring an AST or fabricating those IDs from the expected case would either reject the intended negative or trust the certificate without proving the invocation's inputs.

The negative observation may be admitted only when independently established facts join exactly: (1) fresh current `verified/lib.rs` and `original/lib.rs` bytes match the immutable certified source package and `original == ghost.strip_ghost(verified)`; (2) the raw focus observation's source/unit IDs, source-certificate digest, and verified/original pair hashes match those actual bytes and certified case; (3) the forced redirect control JSON is exact, unchanged, and its digest equals both the prepared control inventory and the run result; (4) paired source support passed; and (5) the same invocation ended at a terminal integer exit 2 with the fresh verifier log hash and the intended first fatal translator diagnostic. Any missing, null, malformed, stale, contradictory, setup-failure, timeout, or earlier unrelated error remains inconclusive. This negative-stage input identity is separate from the positive AST requirements; it does not make a cut or refused translation proof evidence, and all observations retain `proof_credit: false`.

Implementation is limited to the runner: factor the existing positive source-pair check into one strict helper, use it at its existing positive point, and also run it before the legitimate early partial return so the control action returns checked IDs and hashes. Harden redirect classification to require the actual terminal exit and same-log diagnostic. Add inert tests with a real-producer-shaped partial observation and mutations of current/certified pair, control, IDs, stage/log, timeout, and competing diagnostics; verify the resulting redirect observation still passes the pure matrix classifier only for the intended, fully joined refusal. Do not synthesize IDs from certificate-only metadata or reuse a historical observation.
