The source writes to `scratch` are scratch storage, not ownership evidence by themselves. `sort4_stable` uses raw copies and the helper later uses `MaybeUninit`, `insert_tail`'s `ManuallyDrop`/gap guard, and `CopyOnDrop` to move logical ownership through the algorithm. A proof must show which location owns each `T` at every normal/unwind boundary; pointer ranges being numerically disjoint is not a substitute. The stable impl has no `Copy` bound. Its `size_of`/`len` branch selects `sort8_stable` versus `sort4_stable`; this is different from the unstable `CopyMarker` network specialization and must stay out of this proof unless a separately scoped source/caller target requires it.
