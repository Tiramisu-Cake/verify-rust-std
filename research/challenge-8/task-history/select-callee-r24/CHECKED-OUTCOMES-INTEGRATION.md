# Exact R24 integration

The R24 runner applies row29 after the unchanged translator103 chain, parser6a,
and lossless R15 AST printer. It checks patch/base/result hashes and the final
four-file tool inventory. Profile metadata records the actual result translator;
the historical manifest/profile remains unchanged.

The explicit CLI option `--checked-pointer-outcomes` requires the live exact R24
Cloud session and R21 route. Ambient flag, malformed boolean, and wrong route are
rejected before proof execution. All eight ordinary proof variants receive the
new flag only for the unchanged O26 proof callback. Baseline positive AST runs
first without the flag; fingerprint capture never gets it. Callback finally
restores the opt-in keys even when the original exception propagates. Stage
metadata says only requested, never accepted or proved.

Default-off call behavior and classifier/target mappings remain unchanged. The
seven exact control targets may be pinned only after a clean actual positive.
No Rust/ghost/source or captured MIR bytes changed, so fingerprint739f982d is
reused. All same-unit checked callee bodies still require ordinary verification.
Controls that fail earlier cannot establish the final projection counter marker.
The native checker, prelude fn_outcome_result, unwind/abort, Drop/leak,
ownership/provenance, normal postconditions, and validity/refinement gates are
not changed. New translation and formal results require Cloud compilation/proof.

Validation distinction: the worker initially supplied six static/synthetic tests.
The candidate retains two actual patch/hash reproduction checks; the separately
implemented toy admission/call-shape models and string checklist were removed
because they do not execute the translator. Four entry tests execute the real
Python callback and verify flag isolation, both variants, default-off behavior,
exception identity/cleanup and pre-execution route refusal. Exact OCaml gates
require independent static review and Cloud execution; no toy model is credited
as executing those gates.
