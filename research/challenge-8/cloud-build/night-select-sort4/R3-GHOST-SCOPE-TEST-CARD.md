# R3 ghost-scope TEST Cloud lane

This lane is a diagnostic of the nine-command R3 source. It first retains the normal R3 source/MIR/refinement capture and the full same-source proof logs. It then copies the R3 tool outside packaged evidence, checks the exact parent translator and TEST patch pins, and rebuilds only the console with a paired, default-off ghost-scope TEST.

The TEST applies only under exact R3 admission. Controls run with the TEST pair absent and partially set; the enabled run records the full proof log and its first substantive boundary. Complete source, tool, binary, kernel, specification, exporter, and refiner snapshots remain in evidence. A setup error, changed input, wrong control refusal, or incomplete log is inconclusive. Any enabled outcome remains a diagnostic; neither nested Drop verification nor full actual `sort4` safety is credited.
