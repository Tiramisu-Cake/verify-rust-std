## Next checked adapter: design only

Capture is a separate producer. Its borrowck MIR is copied with regenerated region IDs; its point locations do not directly identify a reference in the emitted drop-elaborated MIR. Before using a row, a future adapter must bind the source/version, definition, capture body/phase, actual Ref site, region and place/type, then check an explicit correspondence to the emitted body. A matching span, local name, numeric region ID or diagnostic hash alone is insufficient. The current 64-bit debug hash is navigation metadata, not authority for equivalence.

The capture currently lacks a checked typed borrow-site/cross-stage adapter. Its string rows and counts are useful observations, not a proof of NLL lifetime closure. In particular, unavailable origin_live_on_entry is not an empty live set, and loan_killed_at alone does not produce lifetime_dead_token.

The concrete array3/u64 resource step must consume the same initialized array and element ownership through checked Array_to_array/array_to_Array and slice_full_borrow_content, using the existing begin_lifetime/borrow/end_lifetime/borrow_end token protocol. It must restore the same content on each actual normal and unwind edge. as_mut_ptr may expose the data component only after exact slice metadata and borrow authority have been established; a pure pointer conversion cannot supply memory ownership. Preserve the R8 domain, original generic signatures/CFG/posts and all leak/validity/uninitialized/refinement checks.

Required adapter controls include missing capture, wrong definition/body/phase/scope/region/place/type, wrong or out-of-range point, ambiguous correspondence, conflicting duplicate, captured-but-unattached nested body, unavailable derived liveness, normal return, panic/Drop/Resume and source-stage-target mismatch. These controls are prospective and NOT_RUN. The isolated body, raw caller, original caller and diagnostic capture remain distinct claims; none closes arbitrary-n/generic/sorting or independent B2 credit.
