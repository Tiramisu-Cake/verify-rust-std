# R17 isolated array-to-slice borrow lifecycle component

This control adds one ordinary function to the existing R7 array-control campaign. Its runtime body constructs a `*mut [u64]` from the supplied `*mut [u64; 3]` using the existing `core::ptr::slice_from_raw_parts_mut(p as *mut u64, 3)`. That operation supplies only slice metadata. The function neither dereferences the slice nor creates a Rust reference.

The precondition supplies the initialized physical array `*p |-> current` and per-element `own::<u64>(default_tid())` resources. The verified body closes the existing `r16_array3_content`, begins a real lifetime, and calls `borrow(k, P)` on that physical predicate. Thus `full_borrow(k, P)` and `borrow_end_token(k, P)` are produced by the checked RustBelt operation, not assumed. The existing checked array/slice roundtrip lemma is applied to the exact slice value and length three. The function ends `k`, uses `borrow_end` to recover `P`, then opens `P` back to the physical array and element owners. Its postcondition returns those owners and the residual `full_borrow(k, P)` with existential `k`; `borrow_end` consumes the dead token and end token needed to restore `P`.

The original and verified controls use the same runtime function and target statement. The verified source adds the existing helper/roundtrip proof and the checked ghost lifecycle; no lifetime, ownership, reference-validity, or memory premise is added. `create_ref_mut`, Tree Borrows, runtime std changes, and caller code are not involved.

This is only an isolated necessary conversion component. It does not prove original reference creation, the caller's array-to-slice cast, a callee, or normal/unwind behavior, and it grants no proof credit. The prior eleven controls remain in the campaign unchanged.
