A marker with strict opt-in off is rejected before target proof with `Strict lifetime binding requires explicit overnight opt-in`; malformed, duplicate, wrong, outside or nested markers are refused. At strict entry, the verifier freezes outer variable types and type-parameter bounds, refusing unresolved or cyclic inferred types. At normal, return, direct-unwind return and outgoing-goto exits, it restores the same reserved lifetime halves and frees the same locals as the existing block path, then checks current outer bounds, every live heap type argument, exit outer variable types, and entry snapshots for the scoped lifetime. A live scoped chunk is an error; strict mode never invokes the legacy silent heap filter. Only after those checks does it rebase *outer type-parameter bound metadata* in heap type arguments and the bound table to the immutable entry snapshot. Chunk count, predicate symbols, terms, coefficients, sizes and permissions are preserved. A direct exception continuation unsupported by this rule refuses at `Exception escape from a shortened lifetime binding is unsupported`. Ordinary no-marker behavior retains its production path.

The type representation being checked is `Ast.type_` in `src/frontend/ast.ml` and the mutable bound table is maintained by `register_tparam_eq`/`register_tparam_sized` in `src/verifast1.ml`. The relevant strict sites are `freeze_strict_type`, `type_mentions_typedecl_type`, `check_strict_current_bounds` and `continue_outside_scope` in `src/verifast.ml`. In particular, `BoundedGhostTypeParam` contains `bounds.eqs`; each equality has trait arguments and a right-hand type. The old patch rebased a heap type argument before testing it, which could hide a scoped lifetime in those bounds. This candidate tests the frozen original type first. It also checks the current first bound-table entry for each outer type parameter before restoring entry bounds. Rebase changes the bound record attached to an outer type-parameter occurrence, not the predicate's concrete type constructor, its Rust referent or any heap term.
