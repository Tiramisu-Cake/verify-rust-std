# S2 active review — GO before Cloud

Independent source review of S2 inventory projection, phase/profile wiring, and synthetic control sources. No MIR replay, toolchain, Cloud, or raw evidence access.

**Decision: GO**, conditional on the inventory comparison controls and profile-gate controls passing, then the existing exact-commit closure and live coordinator preflight.

`_inventory_comparison()` suppresses only the values of `localDecls`, `basicBlocks`, and `varDebugInfo` in the four selected impl method Body records (two impls × two methods). For each present field it requires one explicit `ListValue`; it preserves field order and presence, so absence on one side still differs. All other Body fields—including contract/ghost annotations, identity, source spans, signature types, clauses, visibility, unsafety, and unknown fields—remain compared. It leaves both parsed records unchanged; the observation returns the normal raw inventory, while the existing artifacts retain the original normal and readonly exports. Body count and higher-level inventory equality remain intact. The pinned VfMir schema declares the three fields as local declarations, basic blocks, and variable debug info; the pinned exporter preprocessor inserts ghost command tags in normal mode but not readonly mode. The projection addresses that known operational representation difference without generalizing to other fields or normalizing IDs.

The bounded first-difference path improves diagnosis and does not affect acceptance. The test source covers changed allowed values with raw-record preservation, asymmetric presence, duplicate/non-list shapes, unknown/visibility changes, identity/type/clause changes, and closed-stream failures. Profile references now consistently select S2 in the coordinator, recipe, entry, runner, backend, and profile-gate test. S2 keeps the existing R5 authorization and experiment protocol identities, budget/window/lane, and original26/N-false31 matrix statuses. Profile entry/runner/helper hashes match the local files. Source-check metadata reports unchanged compiler/schema/exporter and R/C composition.

The normal→readonly projection does not provide proof credit. Existing paired export/decode, source/refinement, caller-binding, native contract/admission, target proof, and N-false31 lifecycle gates remain the evidence path. A Cloud result must establish whether these three fields explain the observed inventory mismatch; this review does not claim that they do.
