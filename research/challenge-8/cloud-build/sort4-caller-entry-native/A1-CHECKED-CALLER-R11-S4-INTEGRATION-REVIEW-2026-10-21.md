## Attempt boundary

The frozen profile selects `full-matrix`, with 1200-second maximum build timeout, 960-second execute cap, 900-second nominal work deadline, 240-second report/upload reserve, and 60-second inner margin. Historical runtime plus four fresh helper-stage caps does not establish fit. Keep fit **UNESTABLISHED** and make one bounded mandatory full-matrix attempt. A timeout, missing stage, failed helper, or incomplete row must remain partial/`NOT_RUN` or `INCONCLUSIVE`; it must not be represented as full-matrix acceptance. Preserve the report reserve and existing budget accounting. Running the helper prerequisites in this same Build makes a separate target-first Build unnecessary for this attempt.

## Limits

The existing same-Build gate correctly keeps all downstream caller/P1 rows blocked until that real helper-stage result validates. No compiler, extractor, preparer, full runner, or Cloud Build was invoked for this review.
