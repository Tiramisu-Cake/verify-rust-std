# Профиль среды: Claude Code

Решение владельца 2026-10-22: нормативные правила SmallSort нейтральны и лежат в [CORE](CORE.md); здесь только то, что зависит от среды. Сессия работает в Claude только по заданию с `Runtime: Claude Code` в CURRENT-TASK. Codex и Claude одновременно не работают. Упоминания Luna, `CODEX_THREAD_ID`, `codex queue`, Codex thread cwd, goal-free thread и `~/.codex` в остальных документах и истории относятся к [RUNTIME-CODEX](RUNTIME-CODEX.md); в Claude вместо них действует этот профиль.

- **Вход.** Worktree `CLAUDE.md` ([CLAUDE-COMPACT](/root/verify-rust-std-evidence-brief/research/challenge-8/agent-workflow/CLAUDE-COMPACT.md)) импортирует CORE и этот профиль; затем CURRENT-TASK → CHECKPOINT/STATUS. `AGENTS.md` Claude не читает: user setting `instructionFiles=claude-md` и `/root/CLAUDE.md`.
- **Запуск.** `cd <assigned worktree> && claude`. Cwd процесса `claude` должен быть worktree: его проверяет `wait`; `cd` внутри команды и `/cd` его не меняют. Режим разрешений задаёт владелец при запуске.
- **Основная сессия и субагенты.** Только основная сессия: Build request/submit/cancel/status с учётом, coordinator, ledger, CHECKPOINT/CURRENT/STATUS, commit/push, `wait run`/`wait ack`. Субагенты — только чтение, анализ и review: без Cloud/coordinator/ledger мутаций, правок проекта, commit/push и вложенной делегации. Субагент получает тот же `CLAUDE_CODE_SESSION_ID`, и watcher его не отличает: правило процедурное.
- **Independent review.** Субагент `smallsort-reviewer` (`~/.claude/agents/smallsort-reviewer.md`; источник — [claude/smallsort-reviewer.md](/root/verify-rust-std-evidence-brief/research/challenge-8/agent-workflow/claude/smallsort-reviewer.md)): Opus 5.5, effort high, отдельный контекст, только чтение, без вложенной делегации. Передай ему путь пакета `smallsort-session review create`, ожидаемые candidate SHA и spec SHA-256 — **без** своих выводов о корректности. В review record записать `reviewer: claude-subagent:smallsort-reviewer`, модель, packet/spec identities и решение. Concrete soundness findings устранить до submit; delta неизменённых границ — тому же reviewer продолжением (SendMessage). Самопроверка автора review не заменяет: если субагент недоступен, review NOT_RUN и submit нет.
- **Ожидание Build.** `smallsort-session wait run` фоновой Bash-задачей (`run_in_background`) по [WATCH-CLAUDE](/root/verify-rust-std-evidence-brief/research/challenge-8/agent-workflow/WATCH-CLAUDE.md), затем закончить turn WAITING; на событие — `wait ack` до изменения CHECKPOINT. Codex `watch start/ack` не использовать.
- **Progress.** Примерно через час — короткое сообщение пользователю в сессии, без ожидания ответа.
- **Контекст.** При сжатии контекста истиной остаются CHECKPOINT, CURRENT-TASK и own ledger, не пересказ чата.
- **RTK.** `/root/.claude/RTK.md` (подключён в `~/.claude/CLAUDE.md`).
